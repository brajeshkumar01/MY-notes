📝 Note Site (HTML, CSS & JavaScript)

A simple and clean Note-taking web application built using HTML, CSS, and JavaScript.
This project allows users to create, view, and delete notes, with data stored locally using browser localStorage.

🚀 Features

➕ Add notes with title and content

🗑️ Delete notes

💾 Notes persist using localStorage

🎨 Simple and clean UI

⚡ Fast and lightweight (no backend required)

🛠️ Tech Stack

HTML – Structure

CSS – Styling

JavaScript – Logic & localStorage

Future Improvements

✏️ Edit notes

🔍 Search functionality

🌙 Dark mode

🗓️ Date & time for notes

🔄 Convert into MERN stack application
